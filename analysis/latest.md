Sur la période observée jusqu'au 2026-11-17, le dépôt recense 260302 événements répartis sur 5111 adresses IP provenant de 67 pays et 411 réseaux ASN. Les activités dominantes concernent le balayage de ports avec 4785 occurrences et l'infrastructure botnet / C2 connue avec 3591 occurrences. Les principaux pays sources incluent les États-Unis avec 2023 événements, le Royaume-Uni avec 908 et les Pays-Bas avec 482.

- Les principaux réseaux ASN identifiés sont AS25369 (Hydra Communications Ltd) avec 897 événements, AS8075 (Microsoft Corporation) avec 683 et AS396982 (Google LLC) avec 408.
- Parmi les autres natures d'événements figurent les requêtes HTTP abusives (285), l'exploitation (CVE, RCE, injection) avec 266 cas et la force brute SSH (176).
- On relève également 102 charges d'injection bloquées par le WAF, 39 réseaux listés Spamhaus DROP, ainsi qu'une force brute SMTP / IMAP et une signature d'exploit UDP.
